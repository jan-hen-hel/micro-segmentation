# Experiment 2

This experiment shows that MPLS-based isolation does not break existing SmartHome setups.

To illustrate the setup, a Smartphone (Android 11, Nokia 7.1) is connected to the SmartHome.
An TP-Link SmartPlug and an IKEA Zigbee lighting system is connected to the smart home

APU-20 is connected additionally for monitoring the WLAN connectivity.
All devices are connected to APU-11. Again, APU-10 is a mesh-gateway. In contrast to experiment-1, the third mesh node (APU-12) is omitted for a simpler setup.
