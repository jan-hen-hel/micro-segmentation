# Microsegmentation

This repository defines the experiment-setup for "MPLS Microsegmentation for SmartHomes".

Each experiment is placed into a dedicated folder that contains all scripts and files for setup.

Please see the individual folders for a description of the individual experiments:

Experiment 1 ([experiment-1/Readme.md](experiment-1/Readme.md)) is a simple proof-of-concept to verify the concept. It shows that 3 IoT devices are isolated correctly

Experiment 2 ([experiment-2/Readme.md](experiment-2/Readme.md)) includes an additional SDN-controller. The controller adapts the isolation rules to topology changes in the network.
This experiment verifies that real world smart home equipment such as a TP Link kasa HS110 smart plug can be used in an isolated setup.

Experiment 3 ([experiment-3/Readme.md](experiment-3/Readme.md)) outlines the cryptographic properties of the isolation. It associates two Raspberry Pi devices. 
The logs show that established associations result in distinct cryptographic keys.

Experiment 4 ([experiment-4/Readme.md](experiment-4/Readme.md)) illustrates a MAC-spoofing attempt. It shows that associations are rejected 
if an incorrect MAC-address is used for the handshake

The experiment are designed to be executed on OpenWRT. The corresponding firmware-images for the lab-environment
are generated by https://github.com/jan-hen-hel/mesh_testbed_generator. To reproduce an experiment, 
one needs to reset the firmware to its factory default settings and execute the specific setup shell scripts in the experiments folder.

The runtime environment of the SDN-controller is not included in this GitHub repository. It needs Debian/Linux Version 10 (Buster) with the ryu-manager packet installed.
