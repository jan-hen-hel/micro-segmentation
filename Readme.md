# Micro Segmentation

This repository defines the experiment-setup for "MPLS Microsegmentation for SmartHomes".

Each experiment is placed into a dedicated folder that contains all scripts and files for setup.
The experiment are designed to be executed on OpenWRT. The corresponding firmware-images for the lab-environment 
are generated by https://github.com/jan-hen-hel/mesh_testbed_generator.

Please see the individual folders for a description of the individual experiments:

* [experiment-1/Readme.md](experiment-1/Readme.md)
